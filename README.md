## Hola, soy Rafael Contreras

Desarrollador de software y automatización con IA en Culiacán, Sinaloa. Trabajo remoto.

Hago páginas web y sistemas a la medida para negocios y gobierno desde 2016. Hoy desarrollo con agentes de IA (Claude Code y Codex) e integro modelos de IA dentro de las aplicaciones: visión, generación de textos, voz y automatizaciones que corren solas.
